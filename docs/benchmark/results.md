# Benchmark results

Generated by `python -m benchmarks.summarise` from `benchmarks/results/2026-10-28-*.json`. Do not edit by hand. Protocol and metric definitions: [plan.md](plan.md).

## Setup

- **Organisation** (`--preset default`): 2,000 users, 200 groups, 10,000 docs, 20,041 chunks, 18,767 tuples, 500 probes (half aimed at topics the user cannot see), k = 10.
- **Per-user selectivity** (share of docs a user can see): p10 1.8%, median 2.8%, p90 5.7%, max 43.6%.
- **Machine:** macOS-15.7.4-x86_64-i386-64bit, 12 CPUs; every service in Docker on localhost (`deploy/compose.yaml`, images pinned by digest), one run at a time.
- **Software:** rag-authz 0.1.0.dev0, Python 3.12.13.
- **Consistency:** `full` unless stated: OpenFGA `HIGHER_CONSISTENCY`, SpiceDB `fully_consistent`.
- **`cached_pre_filter`** is measured with a warm cache (every probe user's list cached, TTL longer than the run); a cache miss costs one `pre_filter`. Its first measurement used a 60 s TTL that expired mid-run on slow lists; the re-run with a 3,600 s TTL replaces those rows (both are in the files).
